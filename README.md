# homebrew-public

Public Homebrew tap for sovnedge developer tools.

```sh
brew tap sovnedge/public
brew install pocket-buddy
```

| Formula | What it is |
| --- | --- |
| `pocket-buddy` | Developer key manager for sovn-keys: SSH keys, git signing and identity tokens |

Formulae and release archives here are published by release workflows in their
source repositories; do not edit them by hand.
